DCCore

An IRC file server for the channels OmenServe built. It sits in your channel, advertises a list of what you share, and sends files and whole albums over DCC to whoever asks. It can fetch from other bots too.

Download the latest release Source on GitHub What's new

What a channel sees, in the bot's own words. Lines between asterisks are private messages and dashes are notices: only the person who asked sees those. Every name here is invented.

What it does

  • Serves files over DCCPer-user and global queues, the slots you choose, and DCC RESUME, so a broken download continues instead of starting over.
  • Packs an album on request!nick !rar <folder> sends a whole folder as one archive, packed when it is asked for.
  • Keeps a searchable listIn .txt, .zip and .rar, rebuilt safely: a scan that fails never replaces a good list, and searches keep working while it rebuilds.
  • Several lists, several channelsBind a list to each channel, each with its own folders, its own advert and its own file types left out.
  • Fetches from other botsAsk for a file, a list or a packed folder, or send one @find and collect every bot's reply. It understands OmenServe and its relatives, SPQR, mxrarserver 2.x and other DCCore bots.
  • Remembers peopleSomeone who disconnects keeps their place in the queue for five minutes and carries on when they rejoin.
  • Defends itselfRolling flood limits, escalating mutes, hostmask bans, and every other bot treated as untrusted.
  • Easy to runA web dashboard, a password-protected admin console over DCC CHAT with a mIRC window for it, and settings you change without a restart.

How people use it

Nothing new to learn if you have used OmenServe or iroffer. Everything is typed in the channel.

@alfaSends you the bot's list.
@find <words>Searches the list. Words in quotes must appear together.
!alfa <file>Asks for one file. Paste the line from the list or the search.
!alfa !rar <folder>Asks for a whole folder, packed as one archive.
@alfa-queShows where you are in the queue.

Get started

  1. Download the latest release and extract it.

    Any folder will do. Your settings are kept in conf/ and your data in data/, and an upgrade never changes either.

  2. Run the launcher for your system. 
    scripts\windows\start-dccore.bat        (Windows: double-click it)
scripts/linux/start-dccore.sh           (Linux)
scripts/macos/start-dccore.command      (macOS)

    It needs Python 3.10 or newer. On Windows, if Python is missing, the launcher offers to install it for you.

  3. Answer the setup questions.

    The first run asks for the bot's name, the server, its channels, your own nick as its admin and the folder you share, or opens a setup page in your browser for them. Then the bot connects.

How it is built

Pure Python, using only its standard library: nothing else to install, except Flask if you want the web dashboard. It runs on Linux, Windows and macOS, and thousands of tests run on all three, with Python 3.10, 3.12 and 3.14, on every change.

For operators who want more: the admin console and its mIRC window, and every feature, and what is planned.

Responsible use

DCCore is for sharing files you have the right to share: your own recordings and creations, public-domain and Creative Commons works, and anything else whose licence allows it. It comes with no content and points to none. You decide what goes into your shared folders, and you are responsible for it.

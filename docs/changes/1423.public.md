- **New: each bot's downloads in a folder of its own.** Turn on *A folder for each bot's files* (`FETCHED_FILES_PER_BOT`, off by default) on the dashboard's Settings page or in the control panel, and what you fetch from SomeBot is saved in `data/fetched/SomeBot/`, the way mIRC can file downloads under the sender's name. Files you already have stay where they are, and fetched lists keep their own place. A nick with characters a folder name cannot hold, like `[Alfa]`, gets a short tag after its name (`Alfa-1d8be4`), so two bots do not end up in one folder by accident.

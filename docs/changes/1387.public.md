- **New: one large file at a time.** `LARGE_FILE_MB` (Settings, *Sharing & queue*; off by default) makes a file of at least that many MB large, and only one large file is then sent at a time, so a few multi-gigabyte requests no longer hold every slot for hours while everyone else waits. Someone whose next file is large keeps their place and waits while another large file is being sent; the slot goes to the next in line, and the console and the Queue page show them as "waiting: one large file at a time". The bot's list never counts as large, and a folder packed with !rar is never held back: its size is not known until it is packed.

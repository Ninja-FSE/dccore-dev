- **Fixed: the first start after an update that rebuilds the search index could fail with "database or disk is full", and kept the bot off IRC for minutes.** Linux SQLite builds overwrote every deleted page through the write-ahead log, so the rebuild needed the index's size again in free disk. The index no longer does that, and every list refresh writes less too. The re-indexing now runs after the bot connects; until it is done, the List Browser's filter waits before it answers.

- **New (mIRC): a dark theme and icons.** `/dccore theme dark` darkens the script's windows (or *Follow mIRC*, which takes mIRC's own dark mode), and `/dccore icons on` puts an icon beside each of the script's menu items and control panel pages; both are on the control panel's mIRC side too. Two small DLLs of DCCore's own do it, `dccore_ui.dll` and `dccore_icons.dll` in `scripts/mirc/dll/` (sources beside them); without them the script looks as before. Copy the `dll` folder beside `dccore.mrc`, update `dccore.mrc` to 1.20.0 and reload it with `/reload -rs dccore.mrc`.

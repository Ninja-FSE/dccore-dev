- **Fixed: asking for a file the bot does not have could leave you "busy" for minutes.** A request for a name that is not in the bot's list made it search every folder on disk for it, which on a large or network library takes minutes; meanwhile every further request from that person was answered "Busy looking up other files". The list is now what the bot serves: a name it does not have is answered "File not found" at once, and a file you add is requestable after the next list rebuild. File types you leave out of the list are not served either, even to someone who knows a file's exact name.

### 📋 The board guide: the Next release view, and the milestone set when an issue is claimed (#1479)

`docs/PROJECT-BOARD.md` describes the board's two views: **Next release** (the four columns, filtered with
`milestone:"Next release"`) and **All items** (unfiltered, formerly View 1). An issue now gets the "Next release"
milestone when it is claimed, so it shows in that view from Todo on, and the commands find that milestone by name,
since its number changes at every release (#2 since v1.18.0). At a release, the milestone's issues that are still open
move to the new "Next release" before the rename. The IDs table names both views.

- **New (mIRC): the settings window is redrawn, and can use DCX.** Every section sits in a titled frame with its labels above the fields, in a window that fits a 1080p screen. `dcx.dll` (DCX, https://github.com/twig/dcxdll, BSD-3-Clause) now ships in `scripts/mirc/dcx/`, unmodified, with Microsoft's `WebView2Loader.dll` and both licences. With it the pages are a tree on the left with the page's name above the page, and every table has columns - the channels, the lists and the channel bindings, the bans: select a row and use the buttons under it. Lists & channels is two tables now, the lists with their folders and the channel bindings, each with its own Change and Remove. Whenever DCX cannot be used - a 64-bit or pre-7.45 mIRC, the folder not copied, or the option *Use the built-in settings window, not DCX* switched on - the same pages open with mIRC's own controls. `/dccore dcx` says which applies, and `/dccore dcx check` tests DCX in your mIRC. Copy the `dcx` folder beside `dccore.mrc`, update `dccore.mrc` to 1.20.0 and reload it with `/reload -rs dccore.mrc`.

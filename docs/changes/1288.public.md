- **New (mIRC): the settings window can use DCX.** `dcx.dll` (DCX, https://github.com/twig/dcxdll, BSD-3-Clause) now ships in `scripts/mirc/dcx/`, unmodified, with Microsoft's `WebView2Loader.dll` that DCX loads at start (so it writes no warning in the status window) and both licences, and the settings window uses it: the tabs and the column of page buttons become a tree of the groups and their pages, and everything else stays as it was. Whenever it cannot be used - a 64-bit or pre-7.45 mIRC, the folder not copied, or the option *Use the built-in settings window, not DCX* switched on - the window you have today opens, as before. `/dccore dcx` says which applies, and `/dccore dcx check` tests DCX in your mIRC. Copy the `dcx` folder beside `dccore.mrc`, update `dccore.mrc` to 1.20.0 and reload it with `/reload -rs dccore.mrc`.

- **Fixed: list rebuilds after a crash or a failed start.** A rebuild you ran by hand that crashed no longer gets the bot's next rebuild killed within seconds: the bot read the leftover progress report as its new rebuild's, "silent for twenty minutes". Now it reads only its own rebuild's report, and clears a leftover one first. A rare failure could leave a rebuild running with nothing following it, refusing every later rebuild as "already running"; the bot now ends it. A rebuild that failed while starting could leave searches and file requests paused until a restart; they now resume, and the rebuild is recorded as failed and raises a dashboard notice. While a rebuild starts, the dashboard now says "Checking the library's folders…" instead of "Scanning the library". On a network drive that stopped answering, that is where it waits.
